协议与按键对照 不需要回头翻文档

计算机按键位作用
W / ↑bit0上移
S / ↓bit1下移
A / ←bit2左移
D / →bit3右移
J / 空格bit4开火（标题/结束页按它开始或重开）
K / Shiftbit5慢速（精确走位）
L / Xbit6炸弹（清屏，按**上升沿**触发一次）
P / 回车bit7暂停 / 继续（上升沿）
发送格式：'@' + 两位十六进制 + '\n'，例如同时按住「右 + 开火」= @18。
固件侧 500ms 收不到包就认为全部松开（看门狗）；本页每次松手/按下都会立刻发一包，另外每 100ms 补一包心跳。
