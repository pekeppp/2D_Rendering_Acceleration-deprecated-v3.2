=N ↵精确设置 N，固件钳位 25–6000，回 EV N=<值>=1375\n
无需回车：上表中除 =N 之外的各行都是单字符命令，按下即执行。
=N 是行命令：必须以 \n（换行 0x0A）结束，例如发送 =1375\n → 固件回 EV N=1375。
物块尺寸：k 在 16x16 → 32x32 → 64x64 → 16x16 上循环（方块与 ALPHA/KEY 的图集精灵一起变），固件按新尺寸重建图集（含 4x4 透明块掩码）、重新初始化场景并重铺两侧，回包 EV size=16 / EV size=32 / EV size=64；屏幕信息条左侧的 SZ= 字段同步显示当前值。三种尺寸下每像素的固定开销被更大的方块摊薄 ⇒ 64x64 的 Mpx/s 最高（可对着 1Hz 成本行 EV cmd path done … cyc/sprite 读）。
列表路径：l 在 DDR 描述符表（硬件取指器展开，省掉每块 9 次外设事务）与原来的逐条下发之间切换，默认是逐条下发（列表路径坏掉也不会让演示看起来死了）。切换是待生效的：按键立刻回 EV dl on pending / EV dl off pending，在下一个帧边界（本帧那张表已被取指器消费完、像素已写提交）才真正生效，生效时回 EV dl on / EV dl off（打开时另有一行 DL_VERSION=… geom=… lists=… 与一行清屏引擎累计计数 clr fb=… to=… err=…，用于确认"整片重铺是否又回到了引擎关键路径上"）；生效后信息条出现 L 标记，另有一次性读数 EV dl 1st list: STATUS=… consumed=… perf=…。列表模式开着时按 l 也能立刻关掉（旧版会因为"有表在飞"而拒绝、只能重启）；待生效期间再按一次 = 撤销（回 EV dl … pending cancelled）。一旦 DL_ERR 置位会打印 EV DL_ERR code=… idx=… fault=… 并自动退回逐条路径，再按 l 可重新启用；bitstream 早于 v2.11（DL_VERSION 读回 0）时回 EV dl not supported … 并保持关闭。
回包：开机打印一次启动横幅；命令被接受时打印 EV ...（如 EV scene=1、EV path=2 HW only、EV N=1375、EV size=64）。
波特率：固件按 BSP 自行设定（默认 115200 8N1）。日志出现乱码说明波特率不匹配，改回 115200 重连。
