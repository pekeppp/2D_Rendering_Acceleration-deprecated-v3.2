## 第 4 部分　分阶段实施路线图

> 每阶段给出：目标 / 关键动作 / 交付物 / 验收标准。按 6~8 周排期估算。

### Phase 0　环境搭建与板卡点亮（2~3 天）

- 安装 Efinity 2025.2（与板卡 demo 同版本，避免 IP 版本冲突）；学习综合/布局布线/下载流程；
- 烧录 `01_Key_led_osc_demo`（LED/按键）、`03_hdmi_tx_demo`（HDMI 彩条）；
- **交付物**：HDMI 出彩条、按键点灯、UART 回显跑通。
- 验收：能独立新建工程、改代码、下载、用内置逻辑分析仪看波形。

### Phase 1　显示通路：帧缓冲 → 屏幕（约 1 周）★最关键

- 例化 **DDR3 控制器 IP**（Efinity IP Catalog，参考 08/09 号 demo 的接法），跑通初始化与读写回环（写一串数→读回对比）；
- 写**扫描输出控制器**：pixel_clk 时序状态机 + 行 FIFO + AXI 突发读；
- 例化 HDMI TX IP（参考 03 号 demo）；
- CPU（Sapphire SoC）往帧缓冲地址写一张测试图（如 8×8 点阵放大色块），屏幕显示；
- **交付物**：DDR3 回环自测通过；960×540@60 显示 CPU 写入的图片。
- 验收：上电即稳定显示，无花屏（重点排查 DDR 初始化、行 FIFO 下溢、跨时钟域）。
- 风险预警：**DDR3 IP 是全程最大技术风险**，一旦卡住全盘皆停——所以放最前面。

### Phase 2　BitBlt 引擎基础：拷贝 + 填充（1~2 周）

- 写 AXI-Lite 从机寄存器组 + 指令 FIFO（BRAM）；
- 写引擎 FSM，先实现 **BLOCK_COPY**（纯搬运）和 **SOLID_FILL**（常量色）；
- 突发读写 + 源/目的 FIFO 先实现简单版（后续优化）；
- 驱动库 blt_copy/blt_fill；Demo：CPU 控制方块随机移动（硬件渲染）；
- **交付物**：屏上多个方块用硬件搬运移动；CPU 只发指令不碰像素。
- 验收：方块移动无撕裂（接双缓冲或先单缓冲观察），指令 FIFO 批量下发生效。

### Phase 3　总线与存储优化 + 双缓冲（约 1 周）

- AXI 突发长度调到最优（对照 DDR 控制器 IP 支持的 Burst 上限），首尾未对齐段的处理；
- 双缓冲：Front/Back + VSYNC 交换，验证无撕裂；
- **纯软件 vs 硬件加速对比 Demo**：屏上实时显示两边 FPS；
- **交付物**：对比数据表（记录在不同精灵数量/尺寸下的 FPS）。
- 验收：960×540@60 稳定；软件渲染在精灵多时明显掉帧，硬件保持 60。

### Phase 4　高级功能：Alpha 混合 + 色彩键控（1~2 周）

- 像素通路加混合流水线：`out = (fg×α + bg×(255−α)) >> 8`（RGB565 三通道各一组乘加，用 DSP；或整型拆位后用查找表省 DSP）；
- 色彩键控：比较器 + 透明像素跳过（不写目的地址 → 省带宽）；
- 精灵引擎：每个精灵可配置"α 混合 / 抠图 / 直接拷贝"三种模式；
- **交付物**：半透明精灵叠加、不规则边缘精灵（品红抠图）完美显示。
- 验收：抠图边缘无残影；α 混合结果用肉眼/截图验证公式正确。

### Phase 5　游戏 Demo 与性能极限（2 周+）

- 弹幕射击（东方 Project 简化版）或幸存者类（吸血鬼幸存者简化版）：对象池、碰撞检测、粒子、分数/血量 HUD（8×8 字库文本渲染）；
- 压测：逐步增加同屏精灵数，记录 60FPS 上限（分 RGB565/不同尺寸、是否开 α）；
- 冲刺项（可选）：引擎改 2px/clk 或提时钟上 1080p；HDMI RX 接摄像头做"实时画面显示"加分；
- 编写设计文档/答辩 PPT/演示视频：架构图、时序图、数据表、对比结果、设计决策。
- **交付物**：完整游戏 Demo + 极限测试数据 + 文档。

### 时间与风险总览

| 阶段 | 预估 | 主要风险 | 缓解 |
| --- | --- | --- | --- |
| P0 | 2~3 天 | 工具链/驱动问题 | 板卡文档有详细步骤 |
| P1 | 1 周 | **DDR3 时序/初始化** | 用官方 demo 接法；多留调试时间；先 25MHz 慢时钟验证 |
| P2 | 1~2 周 | 引擎 FSM bug | 分模块仿真（指令解析/行循环/地址计算单独仿真） |
| P3 | 1 周 | 突发效率不达标 | 用带宽计数器实测，对照 IP 手册调 Burst |
| P4 | 1~2 周 | α 混合位宽/舍入误差 | 先仿真逐像素比对，再上板 |
| P5 | 2 周+ | 游戏逻辑耗时 | 对象池复用；物理尽量简单；引擎异步跑，CPU 只算逻辑 |
