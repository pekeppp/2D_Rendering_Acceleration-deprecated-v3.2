## 1. 集成总览（Phase A 俯视图）

```
25MHz 晶振
   │ PLL（core 100MHz）
   ▼
┌──────────────┐  AXI4 外存口(128)   ┌────────────────────────────┐
│   efx_soc    │────────────────────▶│  efx_axi_interconnect      │
│ (Sapphire    │                      │  slave(主侧)端口：          │
│  RV32+APB)   │                      │  S0 ← SoC 外存口(CPU)      │
│  · UART0     │                      │  S1 ← blt_top 读主机(AR/R) │
│  · Timer/PLIC│                      │  S2 ← blt_top 写主机(AW/W/B)│
│  · APB slave0┘                      │  S3 ← (PhaseB) scanout 读  │
└──────────────┘                      │  master(从侧)端口：         │
        │ APB 0xF810_0000             │  M0 → DDR 硬核 AXI 从口     │
        ▼                             └──────────────┬─────────────┘
┌────────────────────────┐                       128bit │
│ blt_top（我们 rtl/）    │◀─────────────────────────────┘
│  s_axil_*  ← APB桥/从口 │        Ti60 DDR3 硬核控制器(Interface Designer 配置)
│  m_axi_ar/r → 互联 S1   │        + efx_ddr_reset_controller
│  m_axi_aw/w/b→ 互联 S2  │   ▲ 上电自动初始化；AXI 从口 = 上面 M0
│  irq_done   → PLIC      │   │
└────────────────────────┘   DDR3 256MB（帧缓冲 FB0/FB1、精灵区、程序区）
```

接线原则一句话：**CPU 配置走 APB（低速小口），引擎搬像素走 AXI 互联（高速大口），两条路在 blt_top 内部由寄存器/指令 FIFO 与数据 FIFO 分开，互不干扰。**

## 2. 时钟 / 复位

| 网络 | 频率 | 源 | 接到 |
| --- | --- | --- | --- |
| `clk_100` | 100MHz | PLL（25MHz 晶振 ×4 或向导就近） | blt_top.clk、SoC、互联、DDR AXI 侧、ddr_reset_controller(FREQ=100) |
| `pixel_clk` | 37.36MHz（Phase B） | PLL 第二路（误差<0.5%） | scanout 时序、行 FIFO 读侧、HDMI TX |
| `ddr 物理时钟` | 400MHz | PLL/硬核内部 | DDR3（Interface Designer 配，RTL 不碰） |
| `rst_n` | 异步复位/同步释放 | 复位模块 + `efx_pll_autoreset` | 全部模块 |
| `soft_rst` | blt_top 内部 | regs（CTRL bit2 写 1 产生） | 引擎域门控 `int_rst_n = rst_n & ~soft_rst`（已内置） |

> 约束（.sdc）至少三条：`create_clock clk_100 10ns`；Phase B 加 `create_clock pixel_clk 26.77ns`（37.36MHz）；DDR 相关约束从板卡 demo 的 sdc 复制（08/09 号）。

## 3. 模块例化与端口接线表

### 3.1 blt_top（`rtl/blt_top.v`，参数 AXI_DATA_W=128、CMD_DEPTH=256）

| blt_top 端口 | 接到 | 说明 |
| --- | --- | --- |
| `clk` | `clk_100` | 引擎单时钟域 |
| `rst_n` | 全局 `rst_n` | 引擎内部 SOFT_RST 已自处理 |
| `s_axil_awaddr[11:0]/awvalid/awready` | SoC APB slave0 窗口 → 桥 `efx_apb3_2_axi4_lite`（或直接 SoC AXI-Lite 从口） | 基址 = BLT_BASE（例 0xF8100000，以 soc.h 为准） |
| `s_axil_wdata[31:0]/wstrb[3:0]/wvalid/wready` | 同上 | 写数据 |
| `s_axil_bvalid/bresp/bready` | 同上 | 写响应 |
| `s_axil_araddr/arvalid/arready` | 同上 | 读地址 |
| `s_axil_rdata[31:0]/rresp/rvalid/rready` | 同上 | 读数据/状态 |
| `m_axi_araddr/arlen/arsize/arburst/arvalid/arready` | 互联 **S1** 主侧接口 | 引擎读口 |
| `m_axi_rdata/rresp/rlast/rvalid/rready` | 互联 **S1** | 读回数据 |
| `m_axi_awaddr/awlen/awsize/awburst/awvalid/awready` | 互联 **S2** | 引擎写口 |
| `m_axi_wdata[127:0]/wstrb[15:0]/wlast/wvalid/wready` | 互联 **S2** | 写数据（16B/拍） |
| `m_axi_bvalid/bresp/bready` | 互联 **S2** | 写响应 |
| `irq_done` | SoC PLIC（User Interrupt A） | 引擎完成中断（驱动 blt_wait_done_irq） |

> 重要：读口与写口是**两组独立通道**，必须分别接到互联的两个主侧（slave-facing）端口；数据宽度全部 128bit，避免互联做位宽转换。

### 3.2 efx_soc（Sapphire RV32，按《IP核复用分析》5.1 配置）

| SoC 配置项 | 推荐值 | 用途 |
| --- | --- | --- |
| Frequency | 100MHz；I$/D$ 4KB | 与 blt_top 同频 |
| External Memory Interface | On，**AXI4 全双工，128bit** | CPU 到互联 S0 |
| APB Slave 0 / 1 | On | 引擎寄存器（S0）/ 扫描输出（S1，Phase B） |
| User Interrupt A | On（ID 16） | 接 blt_top.irq_done |
| User Timer 0 | On（ID 19） | FPS 计时（sys_ms） |
| UART0 / GPIO0 | On | 打印 / 按键 |

### 3.3 efx_axi_interconnect

| 项 | 值 |
| --- | --- |
| Protocol | AXI4 |
| Data Width | 128（与 SoC 外存口、DDR、blt_top 一致） |
| Slave（主侧）端口数 | 3（Phase A：SoC/引擎读/引擎写）；4（Phase B 加扫描输出） |
| Master（从侧）端口数 | 1 → DDR 硬核 AXI 从口 |
| 地址解码 | 各 slave 端口地址窗口均指向 DDR 区域（只此一个从目标） |
| Arbitration | PRIORITY：扫描输出 > 引擎 > CPU（防行 FIFO 下溢/保吞吐） |

### 3.4 DDR3 硬核 + 复位

- **Interface Designer** 建 DDR block：DDR3、Data Width 16、800MT/s（行/列/组参考 08/09 demo 的 .peri.xml）。
- 例化 `efx_ddr_reset_controller`（Clock Frequency=100），复位链接 `clk_100`；上电自动初始化，一般无需手动。
- 硬核 AXI 从口 = 互联唯一 master（从侧）端口。

## 5. 上板冒烟验证顺序（每步可独立验收）

1. **最小系统**：仅 SoC + UART，打印 Hello + LED 闪（证明时钟/复位/下载链 OK，参考 08 号 demo）；
2. **DDR 回环**：CPU 经 SoC 外存口写一串数再读回比对（证明 DDR 初始化 OK）；
3. **接 blt_top**：软复位 → 推一条 FILL 全屏指令 → 等 DONE → CPU 读 FB0 区域抽查颜色；
4. **引擎读写**：FILL 小方块 / COPY 精灵图 → 回读 DDR 断言（对应 tb_blt_top T1~T3 上板版）；
5. **中断**：开 IRQ_EN，用 `blt_wait_done_irq()` 验证 PLIC 通路；
6. （Phase B）CPU 写 FB → scanout 上屏 → 双缓冲 VSYNC 交换无撕裂 → demo_compare / demo_game 压测。

## 6. 易错点清单（上板前逐条过）

1. `BLT_BASE/DDR_BASE/FB*_BASE` 全部按**实际生成 soc.h** 改，禁止留 PC 占位值；
2. **缓存一致性**：CPU 直写 FB/精灵区后要 fence/清 D$（Sapphire D$ 4KB/64B 行），否则引擎直读 DDR 看到旧数据；
3. 互联/SoC 外存口/DDR/引擎四侧**数据宽度统一 128bit**；
4. 引擎读、写两组主机口**都要接**互联（漏接一组 = 只能取或只能送）；
5. DDR 硬核 AXI 从口突发上限查手册（常见 16~32 拍）；我们引擎每笔 ≤16 拍已兼容；
6. SOFT_RST 会清指令 FIFO——驱动流程：先 SOFT_RST→0→再推指令→GO；
7. Phase B 的 pixel_clk(37.36MHz) 与 core(100MHz) 之间**只用异步 FIFO**，禁止裸打一拍；
8. PLL 若无法精确出 37.36MHz，就近取整并微调 1120×556 时序使刷新率落 59.5~60.5Hz（文档记录实际 M/N）。

---

## 7. 一句话总结

顶层接线 = **一个 PLL 出 100MHz；efx_soc 的 APB slave0 经 AXI-Lite 桥接 blt_top 配置口；
blt_top 的读/写两组 AXI4 主机口 + CPU 外存口一起进 efx_axi_interconnect（128bit、优先级仲裁），
互联唯一从口接 DDR3 硬核；irq_done 进 PLIC ID16**。所有宏地址与 `software/blt_regs.h` 逐一对齐后即可按第 5 节冒烟顺序点亮。
