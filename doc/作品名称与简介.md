# 作品名称与作品简介（赛题二）

> 赛题：基于 RISC-V 与 FPGA 异构架构的 2D 图形渲染加速引擎（Ti60F225I3 板卡）

---

## 一、作品名称（主推 + 备选）

### 主推：芯绘 · CHIPPAINT
**全称：**《芯绘 —— 基于 RISC-V 与 FPGA 异构架构的 2D 图形渲染加速引擎》

取名理由：
- **芯**：异构之芯。RISC-V 逻辑核 + FPGA 加速芯，软硬件协同，恰是赛题核心；
- **绘**：像素之绘。BitBlt 搬运、Alpha 混合、抠图合成，引擎以硬件之笔绘制每一帧；
- **谐音"心绘"**：精心描绘，寓意对渲染质量与帧率的匠心追求；
- 英文 CHIP + PAINT 直白对应"芯片绘图"，简洁好记，与中文名互译。

### 备选 1：灵绘 · SpiritDraw
- **灵**：既呼应板卡厂商"易灵思"，又暗合"精灵（Sprite）"——本作品的主角正是由硬件加速绘制的海量精灵；
- 整体读感轻巧，适合偏"游戏感"的包装。

### 备选 2：迅帧 · BlitzFrame
- 性能向命名：BitBlt + Blitz（闪电），强调"快"；帧 = 每秒 60 帧的稳定输出；
- 适合答辩时强调"帧率对比数据"的呈现风格。

---

## 二、作品简介（主版本，约 480 字）

在早期 2D 游戏机与现代嵌入式 GUI 中，若由 CPU 通过逐像素搬运完成渲染，宝贵的指令周期被机械的访存操作吞噬，帧率骤降。本作品《芯绘》基于 RISC-V 与 FPGA 异构架构，设计了一款挂载于 AXI4 总线上的 2D 位块传输（BitBlt）硬件加速引擎，将 RISC-V 从像素搬运中彻底解放，专职高层逻辑与指令下发。

系统以易灵思 Ti60F225（60K 逻辑单元）为平台：RISC-V 软核运行游戏逻辑与 C 语言驱动；自研 BitBlt 引擎解析"操作类型、源地址、目的地址、宽度、高度"渲染指令，经指令 FIFO 批量接收，通过 AXI 突发读写 DDR3，内部 FIFO 解耦总线延迟；硬件像素通路支持块拷贝、纯色填充、Alpha 混合（DSP 乘加）与色彩键控抠图；扫描输出控制器生成 960×540@60 HDMI 时序，双帧缓冲在 VSYNC 边界交换，全程无画面撕裂。

作品提供三大演示：① 随机方块与多张大图快速切换，屏上实时对比"纯软件 CPU 渲染 vs 硬件加速"的帧率，直观呈现 1~2 个数量级的性能鸿沟；② 弹幕射击游戏，同屏数百精灵经硬件抠图与混合仍稳定 60FPS；③ 压测模式自动逐步加压，量化 60FPS 下的同屏精灵数上限，为软硬件协同设计提供一手数据。

从总线协议、视频时序到软硬接口，作品完整覆盖 2D 渲染加速的关键技术，展示了异构计算"CPU 管逻辑、硬件管像素"的分工之美。

## 三、作品简介（精简版，约 120 字，用于报名表/摘要）

《芯绘》基于 RISC-V+FPGA 异构平台，在易灵思 Ti60F225 上自研挂载 AXI4 总线的 2D BitBlt 渲染加速引擎：指令 FIFO 批量下发、DDR3 突发读写、Alpha 混合与色彩键控由硬件流水线完成，双缓冲 VSYNC 防撕裂；配套弹幕游戏与"软件 vs 硬件"实时帧率对比，60FPS 下同屏精灵达数百个，验证了异构渲染加速的可行性与性能优势。

## 五、使用建议

1. **名称选择**：若作品定位偏"工程实现与性能数据"选《芯绘》；偏"游戏 Demo 展示"选《灵绘》；偏"速度冲击力"选《迅帧》。
2. 简介中的数据（同屏精灵数、FPS 对比数字）待上板实测后填入精确值，答辩前务必与实测一致。
3. 如需英文简介，可基于主版本翻译；芯片型号、分辨率、总线类型等专有名词保留原样。
